# Media Sources and Contribution Boundaries

These notes describe the public portfolio media. Private capture logs and local source paths are intentionally excluded.

## Featured projects

- **Deinosavros:** current Unity 6000.3 project capture. The 76.6-second main film follows one continuous, naturally resolved battle, earned reward, reachable map selection, Chance recovery and return to the map. A temporary script invokes production input handlers; resource costs, native damage, rewards and Chance remain active. Original Unity-process audio is captured through Microsoft ApplicationLoopback and aligned to frame timestamps. Source capture is approximately 20 fps at 1280×720; the 30 fps output duplicates frames without changing gameplay speed. Separate chapters show another genuine battle and the offering-to-combat flow. The earlier silent isolated UI walkthrough remains explicitly labeled. Source hashes and the original Git state were preserved. Hongtao Gao's contribution is menu, map and combat UI; the broader game and artwork are team work.
- **Procedural City:** the 42-second main edit combines fresh city/district views, an excerpt from the existing editor delivery recording, a same-camera local rebuild and street/plaza composition. Scripted tool commands drive the panel. A locked Block_01_01 is preserved while Block_01_02 is rerolled through the existing Python API; numeric instance/material checks show only the target block changed. Fixed-step cinematic capture advances native world time by 1/30 second per output frame, preserving animation timing independently of wall-clock rendering cost. The source project, camera/exposure settings for the comparison and all 942 protected source files are unchanged. The recording is silent and is not a real-time performance measurement.
- **Rhythm Rider:** the new 61.91-second main edit uses four normal-speed excerpts from one completed Unity 2022.3 run. Production lane-shift and jump handlers feed the native collision, judgement and scoring paths. Cyan Perfect and gold combo responses are earned through those paths. Later pattern phases and the authored finish are included; the existing results panel is titled GAME OVER even for the completed run. A separate missed-input take shows native collisions and failure. Original process-specific music/effects are timestamp-aligned and delivered with a uniform 2 dB gain reduction; no replacement soundtrack is added. The full run remains private. Earlier source-unverified gameplay and the silent controller-triggered comparison remain labeled technical references. Original source state and existing project edits were preserved.
- **Ink VFX:** the new 8.23-second main film contains one complete native cycle each of melee, projectile and area attacks from the selected final Unreal 5.7 project. The shorter edit avoids padding with repeated attacks. Projectile coverage includes charge, full travel, endpoint splash and dissipation; the splash is an authored Niagara effect, not evidence of target collision or damage. Longer chapter clips retain the saved native loops for inspection. Fixed-step cinematic capture preserves the original montage timing and 1/30-second native simulation steps; it is not a real-time performance measurement. Temporary cameras and a shadowless directional fill improve ink readability while retaining the original scene lights. All 191 protected source files remain unchanged. The earlier same-project TailErosion 0.78 / 0.0 and isolated OuterEdge_InkDrops comparison remains separate controlled evidence, with temporary changes restored without saving. Character and starter scene: Epic Games. Source motions: Mixamo's Stable Sword Inward Slash, Standing 2H Magic Attack 02 and Standing 2H Magic Area Attack 01. Hongtao Gao's contribution is VFX and timing integration. Captures are silent.
