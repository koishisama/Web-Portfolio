# Media Sources and Contribution Boundaries

These notes describe the public portfolio media. Private capture logs and local source paths are intentionally excluded.

## Featured projects

- **Deinosavros:** fresh Unity project capture on 13 October 2026. The controlled UI sequence invokes the original preview, cancel and confirmation behavior. A temporary map-entry setup is excluded from the video. The recording is silent. Hongtao Gao's contribution is menu, map and combat UI; the broader game and artwork are team work.
- **Procedural City:** existing editor delivery recording and scene images. Scripted tool commands drive the visible editor panel. Panel comparisons describe control states, not an unobstructed geometric comparison. The engine was not rerun for this presentation.
- **Rhythm Rider:** the main gameplay excerpt retains its existing audio; its original source revision is not established. A separate current-project clip invokes the production feedback controller to compare cyan Perfect and gold combo scans. That controlled capture does not validate input or scoring.
- **Ink VFX:** fresh capture from the selected final Unreal 5.7 project on 13 October 2026. Native montages run at normal speed; temporary cameras and fill lighting are used only for recording. Composite effect stills are not isolated-layer renders. The projectile view shows charge/release rather than a full unobstructed impact chain. Character and starter scene: Epic Games. Source motions: Mixamo's Stable Sword Inward Slash, Standing 2H Magic Attack 02 and Standing 2H Magic Area Attack 01. Hongtao Gao's contribution is VFX and timing integration.

## Supporting projects

- **One More Second:** a seven-person, 72-hour GMTK 2026 game jam. Fresh silent menu/dialogue and tool-response captures use the production methods in a controlled runtime session. The normal input path and a complete rescue run are not certified by these captures. Full release credits: https://morton-mao.itch.io/one-more-second
- **Oasis:** fresh normal-render Unreal 5.7 scene capture on 13 October 2026. The footage shows materials and composition, not collision or interaction validation. Poly Haven resources include Wasteland Clouds Pure Sky, Sand 01, Dense Sand, Gravelly Sand, Dry River Pebbles, Large Sandstone Blocks, Modular Fort 01, Namaqualand Cliff/Boulders/Rocks/Stones 01, Tree Small 02, Quiver Trees 01/02 and Wild Rooibos Bush. The user-supplied Sand Ripples Displacement resource is credited separately; its source files are not distributed here. The original Unreal First Person framework and engine meshes are from Epic Games.
